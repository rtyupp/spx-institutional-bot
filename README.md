# 🏛 بوت S&P 500 لرصد المؤسسات والسيولة الذكية (SPX Institutional Bot)

بوت متقدم لمراقبة مؤشر **S&P 500 (`US500`)** على منصة **Telegram** مع تتبع تدفقات كبار اللاعبين وصناديق التحوط في سوق عقود الأوبشن (**CBOE**).

---

## ⚡️ المميزات الفنية والمؤسسية:
1. **مفاهيم الأموال الذكية (Smart Money Concepts):**
   - **كنس السيولة (Liquidity Sweeps):** صيد ضرب ستوبات القمم والقيعان من قبل صناع السوق والتمركز معهم.
   - **كتل الأوامر وفجوات القيمة (Order Blocks & FVG):** التقاط الاندفاعات المدعومة بالحجم المؤسسي العالي ($Volume > 1.5\times$).
   - **كسر الهيكل والاتجاه:** تأكيد الحركة عبر متوسط EMA200 ونماذج BOS / CHoCH.
2. **رصد الأوبشن وتمركزات الحيتان (CBOE Options Flow):**
   - استخراج صفقات البلوك والسويب الضخمة ($\ge \$1M$) لحظياً.
   - تحديد جدران الكول والبوت ونقطة انقلاب الغاما (GEX) والـ Max Pain.
3. **التنفيذ والتداول التجريبي (Capital.com Demo API):**
   - اتصال مباشر بحساب Demo لجلب الأسعار اللحظية وشمعات التداول.
   - إمكانية فتح وإغلاق الصفقات مع تحديد الوقف والهدف آلياً.
4. **شارت تفاعلي خفيف وسريع:**
   - توليد شارت الشموع اليابانية مباشرة ومستويات الوقف والهدف باستخدام **Pillow**.
5. **استضافة مجانية 24/7:**
   - يعمل البوت بشكل مستمر وآلي عبر **GitHub Actions** دون الحاجة لأي بطاقة بنكية أو سيرفر مدفوع.

---

## 🤖 قائمة الأوامر في تيليجرام:
- `/start` - القائمة التفاعلية الرئيسية
- `/price` - السعر اللحظي لمؤشر SPX مع السبريد والتغير اليومي
- `/analysis` - تقرير التحليل الفني والمؤسسي الشامل
- `/decision` - التوصية الاستثمارية المباشرة مع مستويات الدخول والوقف والأهداف
- `/chart` - رسم وتوليد شارت الشموع اليابانية والمستويات الفنية
- `/options` - تقرير تدفقات الأوبشن وجدران الحيتان
- `/capital` - استعلام عن رصيد وصفقات حساب Capital.com
- `/buy` [size] - فتح صفقة شراء تجريبية
- `/sell` [size] - فتح صفقة بيع تجريبية
- `/closeall` - إغلاق جميع صفقات المؤشر المفتوحة
- `/autotrade` [on/off] - تفعيل أو تعطيل التداول التجريبي التلقائي
- `/selftest` - فحص ذاتي لجميع الاتصالات والمصادر
